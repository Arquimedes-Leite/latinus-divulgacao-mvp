# Lanchonete Latinus — Divulgação MVP

MVP web desenvolvido para a divulgação da **Lanchonete Latinus**, reunindo em uma interface simples a exibição pública de produtos e um painel rápido para atualização de ofertas.

## Funcionalidades Implementadas
* **Cardápio Digital:** Exibição dos principais lanches, ingredientes e preços da lanchonete.
* **Seção de Promoções:** Destaque visual para a oferta do dia na página inicial.
* **Painel do Proprietário:** Formulário interativo com validação em JavaScript para publicar e atualizar promoções em tempo real.

## Tecnologias Utilizadas
* **HTML5** para estruturação semântica da página.
* **CSS3** para estilização responsiva e organização visual.
* **JavaScript** para manipulação do DOM e validação do formulário.

## Como Executar o Projeto
1. Faça o download ou clone este repositório.
2. Abra o arquivo `index.html` diretamente em qualquer navegador web moderno.
